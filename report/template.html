How to read this

  • Events counts a process and everything it spawned (up to ancestor levels), because skip_events_by_process also suppresses descendants. Subtrees overlap, so shares do not add up; the selection total above counts each retained chain once.
  • Names are the kernel comm (15 characters); they are what the agent matches.
  • infra init, container runtimes and similar parents: skipping one hides the whole subtree below it, which can be most of the node.
  • shared shells, interpreters and common utilities: skipping one hides every process of that name on the host, not only the noisy one.
  • Skipped processes are not visible to detections and metrics. Prefer the narrowest entry that covers the volume.
  • Numbers describe this capture window only; check that it is representative before applying the list.
